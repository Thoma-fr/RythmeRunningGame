## About This Fork

This repository is a fork of a project originally developed by three gameplay programmers: **Artyu24**, **AkuroP**, and myself.  
Original project: [UbiArcadeRun](https://github.com/Artyu24/UbiArcadeRun/tree/main)

Since I was the only one interested in continuing the project, I decided to create this fork to:
- Keep an **archive** of the original work.
- **Respect the contributions** of the other programmers.

For obvious reasons, I will **rewrite all scripts that are not mine**, so I don’t falsely attribute their work to myself.

---

## The Project

This is a **rhythm runner game** that I’m developing for two main purposes:

1. Because I simply **want to make a rhythm game**.
2. As a **demo and continuous integration playground** for my rhythm gameplay system:  
   ➜ [UnityRythmeTool](https://github.com/Thoma-fr/UnityRythmeTool)

Gameplay-wise, it’s a **simple runner rhythm game** inspired by *gravity twist* mechanics, with **multiple lanes** (currently 4, but I’m planning to make it “rounder” with more lanes).
